# 视频演讲词(诚实版,总时长 ≈2 分 30 秒)

> 用法:每段左边【画面】是屏幕操作,右边【旁白】直接照着念(语速 ~200 字/分钟)。
> 录制顺序建议:①面板演示(本地验证器,素材可反复录)→ ②终端不变量演示 → ③explorer 证据。
> 全部素材离线可复现,不依赖任何第三方服务在线。

---

## 第 1 段 · 开场(15 秒)

【画面】面板首页(标题 + 三层架构副标题),鼠标缓移过右侧策略卡

【旁白】
「2026 上半年,AI Agent 生态的损失里,98% 来自私钥泄露和恶意指令。我们做了一件事:给 Solana 上的 AI Agent 每一笔交易,加一个签名前的检查点——不是又一份审计报告,是一道真的会拦下交易的防火墙。三层:离线规则、链上模拟、链上金库。」

---

## 第 2 段 · owner 钓鱼(20 秒)

【画面】点击「🎣 Owner 权限钓鱼」→ 红色判定卡出现,鼠标圈一下红色「✗ 拦截」

【旁白】
「先看 Solana 独有的攻击面:Agent 被诱导签一笔"免费领空投"的交易,实际效果是——它的账户 owner 被静默转移给恶意程序,签完就永久失去控制权。这笔交易在签名之前,就被第一层拦下来了。这是只有 Solana 才有的攻击,也是我们的核心场景。」

---

## 第 3 段 · 静默 Drain(25 秒)—— 最核心的一段

【画面】点击「🕳️ 静默 Drain」→ 判定卡出现,鼠标指向「声明 0.002 实转 0.04」字样

【旁白】
「更狡猾的攻击:Agent 声明的意图是转 0.002 SOL,但交易代码里实际转出 0.04。传统的意图检查只看声明——放行了。我们的做法是:声明永远只当上限,不当事实。防火墙去解析交易字节、去链上模拟执行,发现真实流出是声明的 20 倍——拦截。被注入的模型可以伪造意图,但伪造不了解析出来的事实。」

---

## 第 4 段 · 权限突变 + 对照(25 秒)

【画面】切换到终端,运行不变量演示(无限 Approve → INV_I2 拦截输出);再切回面板点「✅ 对照组」显示绿色「✓ 放行」

【旁白】
「代币层面的攻击同样覆盖:有人诱导 Agent 做一笔无限授权——delegate 被打开,之后代币可以被随时清空。模拟执行的前后状态比对发现这个权限突变,直接拒绝。对照组说明我们不是一刀切:限额内、白名单协议、目的明确——放行,正常业务不受影响。」

---

## 第 5 段 · 链上证据(20 秒)

【画面】浏览器打开 explorer.solana.com 的 testnet 交易链接,鼠标指向错误码 6000/6002/6003

【旁白】
「刚才那些是演示。这些是真实链上的记录:验证器真实执行了每一笔攻击,并且真实地拒绝了它们——超额、超日限额、非白名单协议,全部是链上 revert。第三层,是一个链上金库:Agent 的私钥对金库里的资金零权限,就算私钥完全泄露,支出也必须通过链上的身份、限额、白名单检查。」

---

## 第 6 段 · 收尾(25 秒)—— 诚实披露

【画面】回到面板首页,侧栏下滑;最后停在「已知边界」或 README 的威胁模型页

【旁白】
「最后,诚实地讲我们还没做到什么:我们拦不住"价值公平性"——Agent 声明 1 SOL 去换一个只值 0.1 的骗局代币,效果上是合规的;legacy 交易的深层模拟有边界,我们建议全部用 V0。但这些是已知边界,不是未知风险——每一层防什么、防不住什么,都写在仓库的威胁模型里。给 Agent 装防火墙这件事,我们不是第一个做,但把"不信任 Agent 自己"做成架构纪律、并闭环到链上,是这条路线上扎实的一步。谢谢。」

## 与旧话术的差异(为什么这样讲)

| 旧 | 新 |
|---|---|
| 主打「反提示注入四门拦截」 | 主打「声明永不当事实」+ 链上金库——都是代码里真实成立的 |
| 隐藏边界 | 主动披露边界,转成加分项 |
| 「新范式」类措辞 | 「成熟路线上的扎实一步」 |
