# 演示讲解指南(Colosseum 路演 / 视频旁白)

> 配套资产:可视化面板 http://127.0.0.1:3000(中英切换)+ testnet 链上证据链接 + demo/pitch.ts(离线四幕)。
> 受众:评委/投资人。时长:3 分钟以内。讲解人背景卖点:**网安 + AI**。

## 0. 一句话定位(开场必背)

> 「我们给 Solana 上的 AI Agent 装了一道防火墙——交易在签名前经过三层防御,
> 即使 Agent 被提示注入、私钥泄露,资金也出不了链上金库。」

## 1. 开场 30 秒:问题(数据 + 攻击面)

1. **数据**:2026 上半年 AI Agent 生态损失中 **98% 来自私钥泄露与恶意指令**(2026-07-28《2026 上半年安全报告》——话术.md 里你已核对来源)
2. **攻击面差异**:现有方案(Multisig/人类审批)是为人类设计的——慢、不能逐笔审。而 Solana 有一个**独有的攻击面:账户 owner 可以被一条指令静默转移**,钓鱼交易签名即失资产。往届获奖项目(YieldCompass / StableGuard)都没覆盖这个面
3. **一句话过渡**:「我们做的,是给 Agent 的每一笔交易加一个零信任检查点」

## 2. 演示主体 90 秒:面板五个剧本(边点边讲)

> 节奏:每个剧本 10-15 秒。先一句话说攻击,点按钮,指着判定卡说拦截原因。
> 中英界面:给国际评委看英文,讲中文解说(或反过来);切换键在右上角,本身就是一个演示点。

**🎣 Owner 权限钓鱼(Solana 特有,第一个点,制造"哦原来还有这种攻击")**
- 讲:「Agent 被诱导签一个"免费领空投"的交易,实际效果是——它的金库账户 owner 被转移给恶意程序。签完就永久失去控制权。」
- 点 → 指红色判定:「第 1 层 credibility 门在签名前拦截。这道攻击面只有 Solana 有,也只有我们覆盖了。」

**🕳️ 静默 Drain(核心亮点,重点讲,停留最久)**
- 讲:「更狡猾的攻击:Agent 声明的意图是转 0.002 SOL,但交易代码里实际转出 0.04。静态分析只看声明金额——放行了。」
- 点 → 指判定:「第 2 层模拟执行把交易放到链上真跑一遍,发现净流出 0.04 远超声明——UNEXPECTED_DRAIN,拦截。**这个只有模拟执行看得见。**」

**💸 超额转账 + 🚫 黑名单协议(快速带过,30 秒两个)**
- 讲:「限额与黑白名单是第 1 层四门协议(CLAW)的另外两门,毫秒级、完全离线,Agent 体感零延迟。」

**✅ 对照组(必点,消除"一刀切"疑虑)**
- 讲:「限额内、白名单协议、目的明确——五门全过,放行。防火墙不挡正常生意。」

## 3. 链上证据 30 秒(把"演示"变成"事实")

- 切到 explorer 标签页(准备好的 testnet 链接):
- 讲:「刚才是演示环境。这些是真实链上的交易记录——Custom 6000 超额拒绝、6002 日限额拒绝、6003 非白名单拒绝。**验证器真实执行了这些攻击,并真实拒绝了它们。**」
- 指侧栏「部署状态 ✓ 可执行」:「第三层就是部署在链上的强制金库:Agent 的签名密钥对金库资金零权限,所有支出必须通过链上检查。就算攻击者拿到 Agent 私钥、绕过前两层,超限支出依然无法发生。」

## 4. 收尾 30 秒:架构 + 人 + 未来

1. 架构一句话:「三层:客户端快速拒绝 → 模拟执行验证 → 链上强制。默认拒绝,任何一层不过就拦。」
2. **人**:「我本人是网安 + AI 背景——这个项目的攻击模型来自真实攻防视角,不是教科书题目。」(founder-market fit)
3. 未来(一句话,证明想得远):「黑客松之后:TEE 密钥托管、策略 UI、主网。」

## 5. Q&A 预案(评委大概率问)

| 问题 | 答法 |
|---|---|
| 和 Multisig/人类审批比有什么不同? | 人类审批不能逐笔、有延迟;我们对每笔交易毫秒级自动判定,且覆盖 Simulate 才能发现的隐藏攻击 |
| 性能/延迟? | 第 1 层离线解析,毫秒级;只有需要深检时才走模拟执行(~百毫秒);链上执行是 Solana 原生速度 |
| 误报怎么办? | 分级处理:monitor 模式降级为人工确认,不中断业务;策略可调 |
| Agent 私钥泄露了怎么办? | 这正是第 3 层存在的原因:链上金库,私钥对资金零权限 |
| 和别的项目(往届)差异? | 他们做审计报告/静态规则;我们覆盖 Solana owner 攻击面 + 模拟执行 + 链上强制三层闭环 |
| 商业化? | SDK 免费开源 → 企业级策略服务 + 审计报告(路线图第⑥⑦步) |
| 为什么是 Solana? | AI Agent 交易密度最高的链,owner 攻击面独特,团队熟悉 |

## 6. 实操要点

- **预热**:录视频/路演前把五个剧本各点一遍,消除冷启动等待;确认 RPC 状态灯绿色
- **不要读屏幕**:讲解词背熟框架,数字只记「98%」和「0.002/0.04」两个
- **手要指**:每张判定卡出现时,手指屏幕(录屏就鼠标圈一下)
- **断网预案**:如果现场网络抖,切离线版 `npm run pitch`(四幕终端演示,零依赖)——话术.md 有对应讲解词
- 时长控制:开场 30s + 演示 90s + 证据 30s + 收尾 30s = 3 分钟
